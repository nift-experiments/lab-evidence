Deno/Temporal retain single changed-input observations. No Linode measurement is required: website-generator retained all incremental RSS, while shell/scripting and their archives have no incremental site-build workload. **Zero Linodes created/deleted; no cloud credential configuration accessed.** All migration working trees remain untouched. Supplemental AI SDK runs use disposable exports. No Nift implementation changes or optimizations.

## Reporting convention

When changed-input or incremental timing is published, capture and report peak memory for the same workload whenever technically meaningful. Preserve the exact memory metric and qualification. Full-build memory alone is not a substitute for iteration memory.
