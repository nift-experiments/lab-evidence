## Method and counts

Shell: 76 jobs each in prepared and fresh-HOME states. Prepared startup 100 samples, fresh startup 30; work 10; three warmups each. Total 6,580 measured observations and 456 warmups. Scripting: 188 jobs, ten measured samples and two warmups each; 1,880 measured observations and 376 warmups. All serial participant rotation and exact workload/oracle definitions remain unchanged. PTY prompt latency and process invocation have different boundaries; RC-body diagnostics are never subtracted. Waited-child RSS is high-water memory, not simultaneous process-tree aggregate.

## Prior-series review and publication validation

The previous scripting node exposed EPYC 7642; both current nodes expose EPYC 7542. Competitor runtime versions match the prior pins. Nift large calls measured 217.711 ms (prior 292.973), frequency counting 458.982 ms (540.750), sort-index 1467.911 ms (1208.725), JSON parse 266.343 ms (201.221), BFS 816.301 ms (718.199) and filesystem traversal 125.503 ms (129.740). These are cross-node observations, not isolated version effects. No dramatic Nift-only shift in sustained scripting warranted an additional old-source build; no separate version-attribution claim is made.

The fresh-state Nift bare pipeline median was 7.826 ms versus prior 4.896; its p99 was 12.815 ms. Prepared pipeline was 5.528 ms versus 4.961. The state difference and short process-bound workload limit attribution; every tail remains in raw data. Bash small no-op also shifted, with current 4.011 ms versus prior 2.525. No retry was used to select a better result.

Full native Labs build and route/fragment/asset/metadata validator passed: 14 HTML pages and 282 local references. Both current reports passed browser checks at 1440, 390 and 320 px: no document overflow or broken charts, aligned numeric headers/cells and keyboard-focusable table regions.
