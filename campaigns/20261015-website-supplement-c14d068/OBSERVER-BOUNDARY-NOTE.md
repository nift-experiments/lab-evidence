# Observer control boundary

Primary/default-main and replay use the frozen C supervisor clock. The separately labelled observer controls wrap the product with GNU time and record outer Python Popen wall time. GNU-time-only uses Python wait(timeout), whose completion polling can add up to approximately50ms. The proc50ms control also polls every50ms and can add a similar final delay. Therefore differences from C-supervised no-observer timing include wrapper/wait-boundary overhead, not only proc sampling cost. These are observer controls, never substitute them for primary product timing. GNU time retained reports also expose its own lower-resolution target elapsed time and user/system values; process/thread samples preserve target and time-wrapper identities individually. Default-main CPU/wall uses exact C wait4 CPU sum and wall boundaries.
