# Targeted same-node diagnostic

Prior and candidate artifacts are separate clean source builds, with source/compiler/artifact identities in launch.json. Official accepted observations are untouched. All warmups and three paired measured samples per version are retained, alternating order. Independent audit recomputes exact result digests where available, sample sequence, distributions and percentages. Values are descriptive, not a formal significance claim. Template fresh control uses stdout PIPE capture rather than the official temporary-file transport; its paired old/new transport is identical. Source-render clock is the adapter's same internal steady clock and exact output validation. Concurrency control uses the frozen readiness-clock helper and new runtime for each request.
